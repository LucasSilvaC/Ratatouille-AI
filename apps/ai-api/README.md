# API de IA

Futura aplicação Python/FastAPI. Expõe geração de planos, substituição de itens e consulta de execuções. Valida autenticação e autorização, recebe snapshots versionados do perfil e conecta as dependências dos pacotes. Rotas finas; regras ficam em recommendation. Planejar schemas Pydantic, configuração, testes e exportação OpenAPI. Nenhum endpoint está implementado.
