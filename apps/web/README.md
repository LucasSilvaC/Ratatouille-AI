# Web-app

Aplicação Next.js em `apps/web`. Execute `pnpm dev` pela raiz e abra
http://localhost:3000. A demonstração de planejamento alimentar é inteiramente
local, sem necessidade de banco ou variáveis de ambiente. A galeria fica em
`/componentes`.

Veja [arquitetura frontend e cenários mockados](../../docs/frontend-demo.md).
Para trabalhar na infraestrutura de exemplo existente, consulte o
[README principal](../../README.md) e [a arquitetura geral](../../docs/architecture.md).
