# Recomendação alimentar

Biblioteca Python de regras e casos de uso. Filtra candidatos, aplica restrições, usa o preditor de afinidade por interface e valida planos. Independente de FastAPI, Next.js e provedores LLM. Embeddings não comprovam equivalência nutricional. Regras nutricionais precisam de especificação e validação profissional.

Status: implementação inicial em `src/` com testes em `tests/`; ainda não integrada ao web-app. As regras nutricionais exigem especificação e validação profissional antes de uso clínico.
