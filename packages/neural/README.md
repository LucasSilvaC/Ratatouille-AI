# Rede neural de afinidade

Futura biblioteca Python para ranking de paladar. Pode começar com MLP em PyTorch; a arquitetura será escolhida após avaliação dos dados. Inferência recebe features e retorna scores com versão do modelo. Não decide segurança alimentar. Usar fallback por preferências e regras enquanto não houver dados. Pesos e datasets grandes ficam fora do Git.

Status: estrutura planejada; sem implementação nesta etapa.
